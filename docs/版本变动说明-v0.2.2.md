## 二、新增 / 增强能力

### 1. 服务点评「帮我写评价」

- **入口**：对话内 `ReviewCard`、兜底假页 `/review`
- **实现**：`src/utils/generateReviewDraft.ts`
- **输入**：星级、已选标签、订单票种、`scenic.json` 景区名与关键词
- **输出**：约 40–60 字评价草稿，**只填入文案框，不自动提交**
- **降级**：无 API Key 或 LLM 失败时使用离线模板
- **奖励规则不变**：优质评价仍需 >20 字 + ≥2 图（AI 草稿可满足字数，图片需用户上传）

### 2. 场景实现对照表

- 新文档：[`docs/场景实现对照表.md`](./场景实现对照表.md)
- 覆盖游前 / 游中 / 游后：规划功能点、Skill、实现状态、细分触发条件与展示字段
- 已链入 `README.md`、`项目现状.md`

## 六、升级说明

```bash
npm install
npm run dev   # http://localhost:5172
```

- 配置硅基流动 API Key 后，「帮我写评价」走 LLM；未配置时自动离线模板
- 本地业务配置覆盖（LocalStorage）不受本版影响
