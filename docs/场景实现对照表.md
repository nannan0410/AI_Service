## 三、规则引擎公共字段（欢迎入口 / RecommendEntry）

`mock/rules.ts` → `buildRuleContext` 产出，供入口显隐：

| 字段 | 含义 |
|------|------|
| `personaId` | `demo_new` / `demo_mid` / `demo_vip` |
| `memberLevel` / `tags` | 会员等级、标签（`field_catalog`） |
| `inPark` | 是否在园 |
| `visitorPhase` | `pre` / `in_park` / `post_later`（由 inPark、可开票/已完成订单推导） |
| `hasPendingVisitOrder` | 是否有未过期待出行（`visitDate`≥今天且 paid） |
| `nextVisitDate` / `upcomingVisitOrderCount` / `hasVisitToday` | 最近出行日、笔数、是否今日出行 |
| `hasInvoiceableOrders` | 30 天内可开票 |
| `hasNewGuestCoupon` / `canClaimNewGuestCoupon` | 已有新客券 / 是否可领 |

## 四、各实体「该展示」字段速查（Mock）

| 实体 | 建议展示字段（英文字段 · 中文参考） |
|------|--------------------------------------|
| **票产品** | `productId`（产品 ID）、`name`（票种名称）、`price`（售价）、`ticketTypeId`（票种类型）、`composition`（人数构成，如 2大1小）、`tags`（标签）、`channels`（销售渠道）、`status`（上下架） |
| **账户券** | `title`（券名称）、`type`（券类型）、`value`（面额/折扣值）、`condition`（使用条件）、`expireAt`（有效期）、`status`（可用/已用/过期）、（可选）`couponProductId`（券产品 ID）、`redeemActivityName`（兑换项目名） |
| **订单** | `orderId`（订单号）、`ticketName`（票种名称）、`quantity`（人数）、`totalAmount`（实付金额）、`status`（订单状态）、`source`（来源：自营/OTA/TA）、`visitDate`（出行日）、`invoiceStatus`（开票状态）、`reviewStatus`（点评状态）、`completedAt`（核销/完成时间） |
| **游客** | `name`（姓名）、`idType`（证件类型）、`idNumber`（证件号，脱敏）、`gender`（性别） |
| **活动/项目** | `name`（项目名称）、`category`（分类：游乐/演出/餐饮/零售）、`location`（位置）、`timeRange`（开放时段）、`tags`（标签）、`queueStatus`（排队状态）、`waitMinutes`（预计等待分钟）、`isHot`（是否热门）、`showStartTimes`（演出场次）、`virtualQueue`（虚拟排队配置） |
| **内容块** | `type`（内容类型，如交通/入园）、`title`（标题）、`body`（正文） |
| **攻略综合** | `title`（攻略标题）、`visitDate`（出行日）、`ticketName`（关联票种）、`traffic`（交通指南）、`entryNotice`（入园提醒）、`dayPlan`（日程建议）、`activities[]`（推荐项目列表） |

## 六、读表说明（避免和落地计划打架）

1. **`scenic_recommend`**：规划含游前「标签商品推荐」；**当前只做了演出场次**，商品组合推荐仍属未做。  
2. **`retail_recommend`**：规划独立 Skill；**实现并入** `proactive_marketing`。  
3. **新客领券**：独立 Workflow，不占用 `proactive_marketing` 主路径。  
4. **虚拟排队**：`queue_recommend` Skill + Workflow；在园；免费包（每卡「立即取号排队」→ `/queue/take`）/ 付费单（「¥10元快速排队」→ `/queue/pay`）/ 点名项目。  
5. **欢迎态主动气泡推券（H2）**、**地理围栏/离园推券**：未做。
