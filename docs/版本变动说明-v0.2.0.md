# 版本变动说明 v0.2.0

> **发布日期**：2026-07-08  
> **分支**：`dev`  
> **上一版本**：v0.1.0（欢迎页 + 基础页面 + Mock 登录）  
> **定位**：阶段二核心能力 + 游前/游后扩展场景演示版

---

## 一、总览

本版本将 AI 客服从「纯文本聊天占位」升级为 **Tool Calling + Skill 路由 + Workflow 编排 + 业务卡片** 的可验收演示系统，覆盖游前购票、攻略、订单查询、新客领券、发票、停车、服务点评等主链路。

| 维度 | v0.1.0 | v0.2.0 |
|------|--------|--------|
| AI 能力 | 离线占位 / 简单 LLM | 10 Tool + 多 Workflow + NLU 语义补全 |
| 对话卡片 | 仅 text | Ticket / Coupon / Order / Guide / Review 等 12 类 |
| 购票 | 无 | 多轮问人数日期 → 推荐 → `/order/submit` → Mock 支付 |
| 配置 | Admin UI 本地覆盖 | `/config` 助手 UI + 业务场景双 Tab |
| 欢迎页 | 本地模板 | RecommendEntry API + welcome_templates 并存 |

---

## 二、新增能力（按模块）

### A. Tool Calling 基础框架

- 注册 10 个 Tool：`getMemberInfo`、`getOrders`、`getCoupons`、`getProductCatalog`、`getContentBlocks`、`getScenicActivities`、`getCommonVisitors`、`issueCoupon`、`createOrderDraft`、`generateTravelGuide`
- `handlers` + `executor` + `formatters` 完整链路
- `ToolProcessPanel` 展示真实执行步骤
- LLM function calling 多轮循环；无 API Key 时关键词离线 fallback

### B. Skill 路由 + Prompt 注入

- 关键词路由 `routeSkillByKeywords`（更长关键词优先）
- **P0-2 语义补全**（有 API Key）：高置信意图直达 Workflow
- 已启用 Skill：`ticket_purchase`、`travel_guide`、`order_query`、`proactive_marketing`、`parking_pay`、`scenic_recommend`（演出场次）、`invoice_service`、`review_service`

### C. 对话业务卡片

| 卡片 | 用途 |
|------|------|
| `TicketCard` / `TicketConfirmCard` / `TicketFallbackCard` | 票品推荐、确认下单、兜底列表 |
| `CouponCard` | 券展示与操作 |
| `OrderCard` | 订单摘要、跳转提交页 |
| `VisitorPicker` | （早期聊天内选游客，现主要移至下单页） |
| `ContentCard` / `ActivityCard` / `GuideCard` | 攻略分段、项目、综合攻略 |
| `PageGuideCard` | 引导跳转 H5 假页（发票「立即开票」、停车等） |
| `ReviewCard` | 对话内服务点评 |
| `scene_recommend` | 餐饮/零售/演出：文案 + 券/活动卡合并为一条 |

- `MessageBubble` 按 `message.type` 分发；支持单气泡内文案 + 卡片 + 按钮

### D. 游前购票（`ticket_purchase`）

- 多轮：问人数（含老人/小孩）→ 问出行日期 → 推荐唯一票型
- 规则：2大0小 = 成人票×张数；2大1小 = 家庭套票；3大1小等提示不支持并兜底
- `createOrderDraft` → OrderCard → `/order/submit` 选手实名出行人 → Mock 支付
- 支付成功跳转 `/orders?tab=1` 或回聊天 system 消息

### E. 提交订单假页

- 路由：`/order/submit?draftId=xxx`
- 展示草稿摘要、条款勾选、Mock 支付
- `POST /api/order/submit`：draft → paid 订单写入用户快照

### F. OTA/TA 订单只读

- `demo_vip` 含 OTA / TA 演示订单
- 订单页与对话 OrderCard 展示来源标签；第三方只读提示，无改签/退票

### G. 游玩攻略（`travel_guide`）

- `generateTravelGuide` + Workflow；支持 `scope`：traffic / entry_notice / recommend / full / in_park
- 绑定最近待出行订单；园内路线展示排队信息
- GuideCard + 保存攻略图（演示 toast / html-to-image）

### H. RecommendEntry 接线

- `GET /api/assistant/recommend-entries` + 规则引擎
- 欢迎态「快捷服务」chips（最多 4）+「游游推荐」问题列表（最多 6）
- 与 `welcome_templates.json` **方案 A 并存**

### I. 联调修债

- 优惠券页 Tab：可用 / 已使用 / **将过期**（30 天内）筛选修复
- API 层补全：`submitOrder`、`fetchTravelGuide`、`fetchRecommendEntries` 等
- `fetchTicketCatalog` 标记 deprecated，统一 `fetchTicketProducts('self')`
- `npm run typecheck` + `npm run build` 通过

## 三、阶段二外扩展（同版本一并交付）

### 新客领券（独立 Workflow）

- `runNewGuestCouponWorkflow`；与购票发券区分（`issueCoupon` purpose: `claim | purchase`）
- 四种回复：成功 / 已领取 / 非新客 / 超领取窗口
- RecommendEntry `new_guest_coupon`、欢迎「猜你想问」过滤领券类

### 发票服务

- 单笔 `/invoice`、批量 `/invoice/batch`
- `runInvoiceServiceWorkflow`：有单「X笔 + 立即开票」→ 批量页；无单固定文案
- 快捷「开发票」→ chat 发「开发票」

### 停车缴费

- 页面 `/parking`；对话 `runParkingPayWorkflow` 引导绑牌/缴费

### 服务点评（P2）

- `runReviewServiceWorkflow` + ReviewCard
- （v0.2.2）「帮我写评价」：`generateReviewDraft` 生成约 50 字草稿
- 单笔限评；优质评价（>20 字 + 2 图）赠券

### 演出场次（`scenic_recommend`）

- `runShowScheduleWorkflow`；**单条** `scene_recommend`（文案 + 演出卡）
- 区分当日下一场 / 明天后天最早场 / 「演出推荐」等非当日（`general`）

### 发票服务（`invoice_service`）

- 有可开票：`您当前有X笔订单可以申请开票` +「立即开票」→ `/invoice/batch`
- 无可开票：`当前没有可申请开票的订单。`
- 快捷推荐「开发票」→ chat 自动发送「开发票」

### NLU 增强

- P0-1 购票槽位、P0-2 Skill 语义路由、P0-3 攻略子意图
- 详见 `docs/对话意图识别与LLM分工.md`

### 配置后台升级

| 路径 | 说明 |
|------|------|
| `/config` | 助手 UI + 业务场景 Tab |
| `/config/ui` | 原 `/admin/ui` 重定向 |
| `/config/business` | Skill 关键词、推荐入口、猜你想问（LocalStorage） |

### 内容与演示数据

- `activities.json` 扩展至 15 项（分类/排队/热门）
- `demo_mid` 三笔待出行订单 + 今日出行欢迎推荐
- 券产品扩展（购票优享券 `cp_prod_manual` 等）

## 十、升级说明（从 v0.1.0 拉代码后）

```bash
npm install
cp .env.example .env   # 可选配置 LLM Key
npm run dev            # http://localhost:5172
```

- LocalStorage 中旧的 `scenic_admin_ui_override` 仍兼容；业务配置新增 `scenic_admin_business_override`
- Mock 用户快照在内存中，刷新后新发券/新订单行为以当前会话为准
- 若快捷「开发票」仍直跳批量页：后台「恢复默认配置」以同步 `recommend_entries.json`
