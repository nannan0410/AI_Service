> **发布日期**：2026-07-21

## 一、总览

相对 v0.2.0，本版重点补齐 **游中餐饮/零售顺势推券**、**演出推荐单条卡片**、**购票多轮提前发券**，并收敛发票对话引导与业务配置后台体验。

| 维度 | v0.2.0 | v0.2.1 |
|------|--------|--------|
| 场景卡片 | 多卡拆分展示 | 新增 `scene_recommend` 单条合并（券 + 活动） |
| 主动营销 | 查账户券为主 | 餐饮/零售询问与下单意图 → 推券 + 推荐 |
| 演出 | 多张 ActivityCard | 单条 `scene_recommend`，区分当日/明日/后天/通用 |
| 购票多轮 | 问人数/日期时纯文案 | 明确购票意图时可提前发营销券 |
| 发票对话 | PageGuide 文案偏长 | 「您当前有 X 笔…」+「立即开票」→ 批量页 |
| 配置后台 | 规则多为 eq | 支持 persona 多选 `in`、列表按优先级排序 |

## 二、新增 / 增强能力

### 1. `scene_recommend` 消息类型

- 类型与载荷：`SceneRecommendPayload`（`dining` / `retail` / `show`）
- `MessageBubble`：单气泡内文案 + CouponCard（可选）+ 多张 ActivityCard + 操作按钮
- 餐饮/零售：「点击查看」进优惠券页；「查看」toast 示意跳转店铺（演示）
- 演出：不展示店铺「查看」按钮，突出场次推荐文案

### 2. 主动营销（`proactive_marketing`）

- 场景分流：`coupon_query` / `dining` / `retail` / `order_intent_dining` / `order_intent_retail`
- 餐饮/零售：查活动 → 查券 → 必要时 `issueCoupon`（`cp_prod_dining_guide` / `cp_prod_retail_guide`）→ `scene_recommend`
- 「有什么券」仍走账户可用券推荐
- RecommendEntry：`member_coupon` 覆盖 mid/vip；入口文案与意图对齐

### 3. 演出项目推荐（`scenic_recommend`）

- `runShowScheduleWorkflow` 输出单条 `scene_recommend`
- 按 `dayKind`（today / tomorrow / day_after / general）区分文案与「下一场 / 剩余场次」
- ActivityCard 支持分类标签、嵌入样式优化

### 4. 购票 Workflow

- 明确购票意图后，在追问人数/日期阶段即可提前推营销券（不必等到出推荐卡）
- 意图收紧：冷启动仅认购票入口说法；人数/日期槽位在会话内解析
- 与攻略 FAQ 分流：「门票怎么用」「几点入园」等不进购票，优先攻略

### 5. 发票服务

- 对话统一引导批量页：`您当前有X笔订单可以申请开票` +「立即开票」
- 无可开票：固定文案「当前没有可申请开票的订单。」
- 快捷推荐「开发票」改为 **chat 发 prompt**（不直跳假页）
- `demo_vip` 补充 2 笔 30 天内可开票订单；批量页顶底栏与内容同宽

### 6. 意图路由 / NLU

- Skill Workflow Gate、`resolveSkillByWorkflowIntent` 与各 intent 工具对齐（演出、营销、攻略优先等）
- `travelGuideIntent` / `ticketPurchaseIntent` 交叉互斥加强

### 7. 业务配置后台（`/config/business`）

- RecommendEntry 规则支持 persona **多选 `in`**
- 推荐入口 / 猜你想问列表按 **优先级降序** 展示
- 编辑表单与克隆逻辑兼容 `eq` / `in` / 组合规则

### 8. 欢迎入口数据调整

- `recommend_entries.json`：交通指南覆盖 new/mid；会员专属券 mid/vip；今日路线/查看订单等规则按 persona 整理
- 新客领券入口规则简化为 `personaId=demo_new`

> 服务点评「帮我写评价」见 **[v0.2.2](./版本变动说明-v0.2.2.md)**。
