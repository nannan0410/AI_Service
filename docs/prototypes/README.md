# AI 客服后台 · HTML 原型

| 项 | 说明 |
|----|------|
| 文件 | [`ai-admin-prototype.html`](./ai-admin-prototype.html) |
| 形态 | 嵌入大系统的**子系统**示意（**无登录页**） |
| 数据 | **Skill关键词 / Skill 场景**共用 2 条示例：`ticket_purchase`（有子意图、启用）、`parking_pay`（无子意图、禁用） |
| 视觉 | 对齐智慧乐园平台常见 Ant Design 后台（主色 `#1890ff`、深色侧栏 + 筛选 + 表格 + 抽屉） |
| 打开方式 | 浏览器直接打开该 HTML |

## 菜单

一级菜单可折叠；二级无图标。

### 对话与配置

| 菜单 | 说明 |
|------|------|
| Skill关键词 | **运营侧**：列表与运维同源；列 SkillID / 名称 / 子意图 / 状态（文案，禁用灰字）/ 操作（**编辑关键字**、日志）。**无启停**（状态只读展示运维结果）。抽屉复用场景布局：其它字段只读展示，仅 **补充关键词**可编 |
| 冲突检查 | **只读**互斥说明；示例 2 条排他规则（优先 Skill / 被压制 / 条件 / 说明 / 示例话术；对齐 `intent_exclusions`）。本 Skill 内唯一由保存校验 |
| UI 配置 | 基础与主色（含色板）/ 形象资源（助手头像、全身图、对话形态图；**不含**会员默认头像）/ **欢迎文案**；底部固定「取消 / 提交」。**不含**演示专用「推荐解释层」 |
| 推荐对话 | 见下方专节（对应 `welcome_questions`；原菜单名「游游推荐」） |
| 快捷服务 | 见下方专节（对应 `recommend_entries`） |

#### 推荐对话 / 快捷服务（列表 + 抽屉）

两页共用：内容区纵向滚动；筛选区仅有状态筛（宽 **100px**）+「查询」，**无「重置」**；无分页；底栏右下「共 N 条」（非粗体）；抽屉宽 **880px**；「+ 添加条件」按钮宽 **100px**。

| 项 | 推荐对话 | 快捷服务 |
|----|----------|----------|
| 列表列 | 优先级、展示文案、点击行为、置顶、规则摘要、状态（开关）、操作（编辑/日志） | 优先级、标题、点击行为、规则摘要、状态（开关）、操作（编辑/日志）；**无图标列、无置顶列** |
| 排序示意 | 优先级降序（置顶优先于优先级） | 优先级降序 |
| 抽屉主字段 | **展示文案*** ≤40；**辅助文案*** ≤100；**点击行为***；图标上传 60×60；置顶开关；优先级 | **标题*** ≤10；**无**辅助文案 / 置顶；其余同左（点击行为、图标、优先级） |
| 点击行为 | 进行对话 / 小程序链接 / H5 链接 / 小程序页面；联动：对话 prompt≤100 / 链接输入 / 页面下拉（占位「加载自有小程序的菜单页面」） | 同左 |
| 展示规则 | 多条件 **AND**；可用字段见下表；标签「展示规则」与「+ 添加条件」同行 | 同左 |

**展示规则可选字段（原型）：** `inPark`（是否在园）、`hasPendingVisitOrder`（待出行·非当日）、`canClaimNewGuestCoupon`（可领新客券）、`canScenicReviewToday`（今日可景区点评）、`hasReviewableOrders`（可评价订单，兼容旧规则）、`hasInvoiceableOrders`（可开票订单）、`memberLevel`（会员等级）、`hasVisitToday`（今日出行）、`tags`（标签，预留）。

> **命名：** 后台菜单与配置页称「推荐对话」；游客端欢迎区区块标题目前仍可能显示「游游推荐」（端上文案可另配）。二者数据同源 `welcome_questions`。

### 主数据

| 菜单 | 说明 |
|------|------|
| 标签管理 | Tab：**订单标签** / **会员标签** / **产品标签**（各维护名称目录）+ **打标规则**（汇总表，列含**标签类型**订单/会员/产品；规则模板固定只配阈值）。订单规则读单现算；会员含规则/手动/喜好映射（对话不回写）；产品仅供产品管理勾选。项目/内容标签待未来项目列表。说明集中在页头蓝条 |
| 产品管理 | 见下方专节（AI 可见合列表；券仍在券管理） |
| 券管理 | 券产品列表骨架 |
| 内容配置 | 内容块 / 项目活动 Tab（项目暂无标签列） |

#### 产品管理（合列表 · 一期）

**必须对接绑定**：按「来源（供应商系统）+ 对接产品 ID」精确查询后选中入库，**不允许纯手工建档**（无对接则无法下单）。

| 项 | 说明 |
|----|------|
| 一期类型 | **门票 / 卡票 / 组合产品**（餐饮、零售需门店筛选，后续再开；门店/虚拟排队仍预留） |
| 列表列 | 对接产品 ID、名称、产品类型、**游玩期限**、**可售期限**、**是否自销可售**、参考售价、标签、**对接状态**（来源左侧）、来源（供应商名）、状态（上下架开关）、编辑 |
| 筛选 | 名称、产品类型（100px）、状态（100px）；无「重置」；底栏「共 N 条」 |
| 抽屉字段顺序 | ① 产品类型* → ② 来源*（对接系统下拉）→ ③ 对接产品 ID* → ④ 选中后只读摘要 → ⑤ 标签 |
| 对接产品 ID | 可搜索下拉：输入后精确查接口；命中则面板显示「ID + 名称」，单击选中；输入框无 placeholder；右侧提示「请输入对接系统的产品 ID，不可重复提交。」 |
| 对接摘要（对接状态上方） | **游玩期限**（有效开始 ~ 有效结束）、**可售期限**（售卖开始 ~ 售卖结束）、**提前售卖期限**（最小预订天数 ~ 最大预订天数）、**是否自销可售**（是/否，是否含自销小程序）→ 再接**对接状态** |
| 门票摘要 | ID、产品名称、门票类型（日历票/期票）、参考售价、上表期限字段、对接状态 |
| 卡票摘要 | ID、产品名称、卡票类型（年卡/月卡/次卡）、参考售价、上表期限字段、对接状态 |
| 组合摘要 | ID、产品名称、组合内容、参考售价、上表期限字段、对接状态 |
| 参考售价 | 非日历实价；实价以选定日期为准 |
| 标签 | 左列为「标签」；「选择标签」弹窗多选**标签管理 → 产品标签**目录（名称 + tagId）；已选可叉掉。与订单/会员标签分域 |
| 上下架 | **仅列表开关**；表单无上架项 |
| 编辑 | 产品类型 / 来源 / 对接产品 ID **不可编辑**（灰底只读）；可改标签。对接产品信息卡片与输入控件左对齐 |
| 抽屉宽 | 880px |

### 系统与反馈

| 菜单 | 说明 |
|------|------|
| 参数配置 | 业务阈值（含可开票/可评价窗口天数等）+ 规则字段只读区（**不含**技术接口对接） |
| 问题记录 | **踩上报** / **赞统计** Tab |

### 运维管理（内部，不对客户开放）

| 菜单 | 说明 |
|------|------|
| 外部接口对接 | 环境级 Base URL / 标识（地图 / 订单 / 天气 / LLM）。**默认查看**，底栏「编辑」；编辑中底栏「取消 / 提交」，取消还原。黄条：「请检查后填写，请勿随意变更影响使用。」 |
| SKILL工具 | **全局工具目录**（能力标识 + 名称 + 默认读写，≤20）。Skill 场景 / 子意图绑定只能从此**下拉选择**，不可手填发明标识。查看 / 编辑交互同上 |
| Skill 场景 | 列：SkillID / 名称 / **子意图（数量，无则 0）** / 状态（开关启停）/ 操作（**编辑**、日志）。**SkillID 新增可填，提交后不可改** |
| 新客券活动（规划） | **绑定券 ID** + **注册后可领期限**；活动领取 **一次性**（换绑券 ID 不可再领）。入口展示看活动资格；点击领取另校券 ID 限领（默认 1 张）。详见《业务场景配置与实现》§11.4 |
| 园区围栏（规划） | 每景区圆心+半径或多边形；供 `inPark` 的 GPS 信号。`inPark`=订单核销∨票夹核销∨围栏内。详见《业务场景配置与实现》§2.4.2 |

**运维 Skill 抽屉（新增 / 编辑同一流程，子意图内嵌）：**

| 入口 | 内容 |
|------|------|
| 编辑 / 新增 | SkillID（仅新增可写）/ 名称 / **绑定工具**（从「SKILL工具」目录下拉选择，≤20；读写不得宽于目录）/ **子意图（0～10）** / **默认关键字** / **补充关键字（只读）** / 场景指令；标题旁展示名称 + skillId（编辑） |
| 无子意图 | 默认关键字可编；补充关键字只读展示（`parking_pay` 示意） |
| 有子意图 | 默认关键字为合集只读；卡片内：名称 + 关键字 + **补充（只读）** + 工具（`ticket_purchase` 示意） |
| 0→1 | 默认 **与补充**一并迁入第 1 条子意图 + toast；N→0 对称迁回 Skill |
| 日志 | 独立抽屉：占位时间线 |

**运营「编辑关键字」抽屉：** 同上布局；隐藏添加工具 / 新增子意图 / 移除整组 / 工具行删除；权限展示为文案「只读 / 写入」；仅补充关键词可编；底栏「取消 / 提交」；禁用 Skill 仍可编辑补充。

列表**不再**提供独立「子意图配置」入口。

**工具绑定链路：**

```
运维管理 → SKILL工具（全局目录）
    ↓ Skill 抽屉下拉选择
Skill.toolBindings（⊆ 目录；读写不得更宽）
    ↓ 子意图再选
子意图.tools（⊆ Skill 池）
```

### 关键字两级口径（摘要）

| 层级 | 归属 | 谁维护 |
|------|------|--------|
| 默认关键字 | 无子意图 → Skill；有子意图 → 各子意图（Skill = 合集只读） | 运维 |
| 补充关键字 | 与默认同级挂载（无子意图 → Skill；有 → 各子意图）；**参与** 0→1 / N→0 迁移 | 运营（运维只读可见） |
| 路由匹配 | 该层 `默认 ∪ 补充` | — |
| 唯一性 | **本 Skill 内**（含各子意图）唯一；勿与同层默认重复；跨 Skill 交给冲突检查 | — |

## 样式约定（与运维 Skill 对齐）

| 项 | 约定 |
|----|------|
| 常规输入 / 下拉 | 宽 **400px**（UI「基础与主色」名称/昵称/标题为 **480px**） |
| 色值 / 短数字 | 色值 **120px**；`.input-num`（120） |
| 助手昵称 | 宽 **480px**（本页），上限 **10** 字 |
| 聊天背景分段 | 总宽 **480px**（每项 160） |
| 必填 | 红星 + 空格：`* 字段名` |
| 名称类字数 | 默认 `x/40`（昵称 `x/10`），按 Unicode 码点计「字」 |
| 表单标签 | 右对齐，约 8em；与 32px 高控件垂直对齐 |
| 抽屉 | Skill / UI 等：**1080px**；**推荐对话 / 快捷服务 / 产品管理：880px** |
| 筛选条 | 左起；窄筛宽 **100px**（状态；产品管理另含**产品类型**）；查询区**无「重置」**（原型已去掉） |

已套用范围：**P0 全局约定** + **P1**（Skill关键词抽屉、推荐对话/快捷服务抽屉、产品管理抽屉、UI 配置表单）。
