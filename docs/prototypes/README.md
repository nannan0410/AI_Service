# 后台 HTML 原型

浏览器直接打开对应 HTML。视觉对齐智慧乐园 Ant Design 后台（主色 `#1890ff`）。

## AI 智能体平台（新）

| 项 | 说明 |
|----|------|
| 文件 | [`ai-agent-platform-prototype.html`](./ai-agent-platform-prototype.html) |
| 形态 | **智能体平台**：左侧 64px 轨道切换智能体；无登录页 |
| 一级导航 | 工作台 + 五个智能体（顺序）：**景区助手** / **AI 标签** / **内容巡检** / **知识库** / **舆情分析** |
| 智能体内 | **对话**工作台 + **配置**（表格 / 抽屉）。**工作台无「对话 / 配置」切换**；进入五个智能体后才显示 |
| 标签拆分 | 原「标签管理」从景区助手迁至 **AI 标签**；助手产品管理仍可勾选产品标签，维护入口在标签智能体 |
| 提示条 | 页内说明统一为**黄条**（`.alert.alert--warn`），不再用蓝条 |

### 布局

- **工作台**：五张智能体卡片（景区助手为首）+ 能力关系说明
- **对话**：左聊天、右上下文；示例 chips 可点（示意假回复，未接模型）
- **配置**：
  - **景区助手**内侧栏四组（**不含标签**）：
    - 对话与技能：Skill 关键词 / 冲突检查 / Skill 场景 / Skill 工具（命名统一 `Skill + 空格 + 中文`）
    - 推荐与外观：UI 配置 / 推荐对话 / 快捷服务
    - 可售与内容：产品管理 / 券管理 / 内容配置 / **问题记录**
    - 系统：参数配置 / 外部接口对接
  - **AI 标签**：订单 / 会员 / 产品目录 + 打标规则 + **打标关系** + 覆盖统计 + 运行日志。运营**不展示标签 ID**（名称同景区同域唯一，改名不改内部键；有关系只能禁用）。目录状态列为开关（字在开关上：启用/禁用；操作仅查看/编辑）。各 Tab 底栏同 Skill 关键词：共 N 条 + 每页条数（默认 20）+ 页码。打标关系列为「更新时间」（`yyyy-mm-dd hh:mm`）。规则逻辑仅预置模板。**关系表一期**：订单规则、会员规则、产品勾选。喜好在会员系统只读对照；对话打标不落库不回写（二期/三期规划）；「手动打标」为规划弹窗。产品 / 会员目录带来源列（**同步不是类型、不是独立 Tab**）：产品演示亲子/成人/儿童来自商品中心、年卡为本页新建；会员为规则模板 / 本页新建 / 会员系统。产品 / 会员标签页有「**同步业务系统标签**」（按名称对齐，toast 示意，不写关系）。运行日志含目录同步。同步**不**产生打标规则。**目录同步与打标关系可分开**：同步走手动/批任务（项目无列表时尤其）；查询路径不 upsert 目录；添加产品只写勾选关系
  - 巡检 / 知识库 / 舆情：规划骨架（待办、文档、看板）
  - **问题记录**（踩上报 / 赞统计）：见下方「系统与反馈 · 问题记录」专节（仅平台原型有完整交互示意）

### 景区助手 · 底栏编辑（查看 / 编辑）

与运维页同一交互：**默认查看**，底栏「编辑」→「取消 / 提交」（取消还原）。

| 页面 | 说明 |
|------|------|
| 参数配置 | 业务阈值可编；规则字段说明区仍只读。**已去掉右上角「保存」** |
| Skill 工具 | 全局工具目录；黄条勿随意变更 |
| 外部接口对接 | Base URL / 标识；黄条勿随意变更 |

UI 配置仍为页底固定「取消 / 提交」（整页可编，非查看态切换）。

景区助手配置页、抽屉与样式复用自 [`ai-admin-prototype.html`](./ai-admin-prototype.html)，再按上表拆导航与改交互；**勿**把本平台的菜单/黄条/参数底栏约定回写到旧单智能体原型，除非同步改该 HTML。

#### 推荐对话 / 快捷服务（列表 + 抽屉）

两页共用：内容区纵向滚动；筛选区仅有状态筛（宽 **100px**）+「查询」，**无「重置」**；无分页；底栏右下「共 N 条」（非粗体）；抽屉宽 **880px**；「+ 添加条件」按钮宽 **100px**。

| 项 | 推荐对话 | 快捷服务 |
|----|----------|----------|
| 列表列 | 优先级、展示文案、点击行为、置顶、规则摘要、状态（开关）、操作（编辑/日志） | 优先级、标题、点击行为、规则摘要、状态（开关）、操作（编辑/日志）；**无图标列、无置顶列** |
| 排序示意 | 优先级降序（置顶优先于优先级） | 优先级降序 |
| 抽屉主字段 | **展示文案*** ≤40；**辅助文案*** ≤100；**点击行为***；图标上传 60×60；置顶开关；优先级 | **标题*** ≤10；**无**辅助文案 / 置顶；其余同左（点击行为、图标、优先级） |
| 点击行为 | 进行对话 / 小程序链接 / H5 链接 / 小程序页面；联动：对话 prompt≤100 / 链接输入 / 页面下拉（占位「加载自有小程序的菜单页面」） | 同左 |
| 展示规则 | 多条件 **AND**；可用字段见下表；标签「展示规则」与「+ 添加条件」同行 | 同左 |

**展示规则可选字段（原型）：** `inPark`（是否在园）、`hasPendingVisitOrder`（待出行·非当日）、`canClaimNewGuestCoupon`（可领新客券）、`canScenicReviewToday`（今日可景区点评）、`hasReviewableOrders`（可评价订单，兼容旧规则）、`hasInvoiceableOrders`（可开票订单）、`memberLevel`（会员等级）、`hasVisitToday`（今日出行）、`tags`（标签，预留）。

> **命名：** 后台菜单与配置页称「推荐对话」；游客端欢迎区区块标题目前仍可能显示「游游推荐」（端上文案可另配）。二者数据同源 `welcome_questions`。

### 运维管理（内部，不对客户开放）

| 菜单 | 说明 |
|------|------|
| 外部接口对接 | 环境级 Base URL / 标识（地图 / 订单 / 天气 / LLM）。**默认查看**，底栏「编辑」；编辑中底栏「取消 / 提交」，取消还原。黄条：「请检查后填写，请勿随意变更影响使用。」 |
| SKILL工具 | **全局工具目录**（能力标识 + 名称 + 默认读写，≤20）。Skill 绑定只能从此**下拉选择**，不可手填发明标识。查看 / 编辑交互同上 |
| Skill 场景 | 列：SkillID / 名称 / **子意图（数量，至少 1）** / 状态（开关启停）/ 操作（**编辑**、日志）。**SkillID 新增可填，提交后不可改** |
| 新客券活动（规划） | **绑定券 ID** + **注册后可领期限**；活动领取 **一次性**（换绑券 ID 不可再领）。入口展示看活动资格；点击领取另校券 ID 限领（默认 1 张）。详见《业务场景配置与实现》§11.4 |
| 园区围栏（规划） | 每景区圆心+半径或多边形；供 `inPark` 的 GPS 信号。`inPark`=订单核销∨票夹核销∨围栏内。详见《业务场景配置与实现》§2.4.2 |

**运维 Skill 抽屉（新增 / 编辑同一流程，子意图内嵌）：**

| 入口 | 内容 |
|------|------|
| 编辑 / 新增 | SkillID（仅新增可写）/ 名称 / **绑定工具**（从「SKILL工具」目录下拉，≤20）/ **子意图（1～10，必填）**；标题旁展示名称 + skillId（编辑） |
| 子意图卡片 | 名称 + 默认关键字 + 补充关键字（只读）+ **结构化场景指令**（角色 / 需追问 / 条件→工具 / 禁止；后端拼装 promptAddon） |
| 约束 | 至少保留 1 条子意图；删至最后一条时禁用「移除整组」 |
| 日志 | 独立抽屉：占位时间线 |

**运营「编辑关键字」抽屉：** 同上布局；隐藏新增子意图 / 移除整组；Skill 层绑定工具只读；子意图内 **场景指令只读预览**；仅各子意图 **补充关键词** 可编；底栏「取消 / 提交」；禁用 Skill 仍可编辑补充。

列表**不再**提供独立「子意图配置」入口。

**工具绑定链路：**

```
运维管理 → SKILL工具（全局目录）
    ↓ Skill 抽屉下拉选择
Skill.toolBindings（⊆ 目录；读写不得更宽）
    ↓ 子意图「条件→工具」引用
子意图.instruction.conditionRules[].tool（⊆ Skill 池；不单独绑读写）
```

## 样式约定（与运维 Skill 对齐）

| 项 | 约定 |
|----|------|
| 常规输入 / 下拉 | 宽 **400px**（UI「基础与主色」名称/昵称/标题为 **480px**） |
| 色值 / 短数字 | 色值 **120px**；`.input-num`（120） |
| 助手昵称 | 宽 **480px**（本页），上限 **10** 字 |
| 聊天背景分段 | 总宽 **480px**（每项 160） |
| 必填 | 红星 + 空格：`* 字段名` |
| 名称类字数 | 默认 `x/40`（昵称 `x/10`），按 Unicode 码点计「字」 |
| 表单标签 | 右对齐，约 8em；与 32px 高控件垂直对齐 |
| 抽屉 | Skill / UI 等：**1080px**；**推荐对话 / 快捷服务 / 产品管理：880px** |
| 筛选条 | 左起；窄筛宽 **100px**（状态；产品管理另含**产品类型**）；查询区**无「重置」**（原型已去掉） |
