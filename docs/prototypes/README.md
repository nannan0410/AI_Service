# AI 客服后台 · HTML 原型

| 项 | 说明 |
|----|------|
| 文件 | [`ai-admin-prototype.html`](./ai-admin-prototype.html) |
| 形态 | 嵌入大系统的**子系统**示意（**无登录页**） |
| 数据 | 多数列表空态；**运维 Skill** 含 2 条示例：`ticket_purchase`（有子意图）、`parking_pay`（无子意图） |
| 视觉 | 对齐智慧乐园平台常见 Ant Design 后台（主色 `#1890ff`、深色侧栏 + 筛选 + 表格 + 抽屉） |
| 打开方式 | 浏览器直接打开该 HTML |

## 菜单

一级菜单可折叠；二级无图标。

### 对话与配置

| 菜单 | 说明 |
|------|------|
| Skill关键词 | **运营侧**：列表、**扩展关键字**（可增删）、启用/禁用；**默认关键字只读**（不含工具 / 场景指令） |
| 冲突检查 | **只读**互斥说明 |
| UI 配置 | 基础与主色（含色板）/ 形象资源 / **欢迎文案**；底部固定「取消 / 提交」。**不含**演示专用「推荐解释层」 |
| 游游推荐 | 列表 + 新增抽屉 |
| 服务推荐 | 快捷入口列表 + 抽屉 |

### 主数据

| 菜单 | 说明 |
|------|------|
| 标签管理 | 目录 / 打标规则 Tab |
| 产品管理 | 门票产品列表骨架 |
| 券管理 | 券产品列表骨架 |
| 内容配置 | 内容块 / 项目活动 Tab |

### 系统与反馈

| 菜单 | 说明 |
|------|------|
| 参数配置 | 业务阈值 + 规则字段只读区（**不含**技术接口对接） |
| 问题记录 | **踩上报** / **赞统计** Tab |

### 运维管理（内部，不对客户开放）

| 菜单 | 说明 |
|------|------|
| 接口配置 | 外部接口 Base URL / 标识；未来合并进运维中心 |
| Skill 场景 | 列：SkillID / 名称 / **子意图（数量，无则 0）** / 状态 / 操作（**编辑**、日志）。**SkillID 新增可填，提交后不可改**（编辑时标题旁只读展示） |

**运维 Skill 抽屉（新增 / 编辑同一流程，子意图内嵌）：**

| 入口 | 内容 |
|------|------|
| 编辑 / 新增 | SkillID（仅新增可写）/ 名称 / 绑定工具（≤20）/ **默认关键字** / **子意图（0～10，同页）** / 场景指令；标题旁展示名称 + skillId（编辑） |
| 无子意图 | 默认关键字在 Skill 上可编（`parking_pay` 示意） |
| 有子意图 | 默认关键字为合集只读；卡片内维护名称 + 关键字 + 工具（`ticket_purchase` 示意） |
| 0→1 | 同页自动迁入 Skill 默认词（方案 B）+ toast；N→0 迁回 |
| 日志 | 独立抽屉：占位时间线 |

列表**不再**提供独立「子意图配置」入口，避免新建后二次跳转导致关键字漏填或重归属。

### 关键字两级口径（摘要）

| 层级 | 归属 | 谁维护 |
|------|------|--------|
| 默认关键字 | 无子意图 → Skill；有子意图 → 各子意图（Skill = 合集只读） | 运维（编辑抽屉内） |
| 扩展关键字 | Skill | 运营（对话与配置） |
| 路由匹配 | `默认 ∪ 扩展` | — |

## 样式约定（与运维 Skill 对齐）

| 项 | 约定 |
|----|------|
| 常规输入 / 下拉 | 宽 **400px** |
| 色值 / 短数字 | `.input-sm`（160）/ `.input-num`（120） |
| 必填 | 红星 + 空格：`* 字段名` |
| 名称类字数 | `x/40`，按 Unicode 码点计「字」 |
| 表单标签 | 右对齐，约 8em；与 32px 高控件垂直对齐 |
| 抽屉 | 宽 1080px；筛选条左起、查询→重置→主按钮 |

已套用范围：**P0 全局约定** + **P1**（Skill关键词抽屉、游游推荐/服务推荐抽屉、UI 配置表单）。
