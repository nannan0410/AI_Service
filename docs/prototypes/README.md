# AI 客服后台 · HTML 原型

| 项 | 说明 |
|----|------|
| 文件 | [`ai-admin-prototype.html`](./ai-admin-prototype.html) |
| 形态 | 嵌入大系统的**子系统**示意（**无登录页**） |
| 数据 | **无 Mock 业务数据**；列表均为空态；表单为结构占位 |
| 视觉 | 对齐智慧乐园平台常见 Ant Design 后台（主色 `#1677ff`、侧栏 + 筛选 + 表格 + 抽屉） |
| 打开方式 | 浏览器直接打开该 HTML |

## 菜单

| 菜单 | 说明 |
|------|------|
| SKILL 场景 | 列表 + 编辑抽屉示意 |

| 券管理 | 券产品列表骨架 |
| 内容配置 | 内容块 / 项目活动 Tab |
| 参数配置 | 接口对接 + 阈值 + 规则字段只读区 |
| 问题记录 | **踩上报** / **赞统计** Tab |
