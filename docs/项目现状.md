## 已完成

### AI 对话与 Tool Calling

- 10 个 Tool + `ToolProcessPanel` 步骤展示
- Skill 关键词路由 + **P0-2 语义补全**（`ticket_purchase` / `travel_guide` / `order_query` 等）
- **Workflow 层（代码正则，优先于 Skill）**：新客领券、购票、游玩攻略（含 **园内路线 `in_park`**）、订单查询、**发票服务**、停车缴费、**演出推荐**、主动营销、服务点评
- **NLU 增强（有 API Key）**：P0-1 购票槽位、P0-2 Skill 路由（含高置信进 Workflow）、P0-3 攻略子意图
- 业务卡片：Ticket / Coupon / Order / Content / Activity / Guide / VisitorPicker / PageGuide / Review / **scene_recommend**
- 单条消息框：领券、攻略、开票引导、餐饮零售/演出推荐等 **文案 + 卡片 + 操作按钮** 同气泡
- 聊天 UI：客服气泡最大宽度（距游客消息 20px）、卡片内容自动换行

详见 [`对话意图识别与LLM分工.md`](./对话意图识别与LLM分工.md)。

### 新客领券

- `runNewGuestCouponWorkflow` + `canClaimNewGuestCoupon` 规则字段
- 四种回复：成功 / 已领取 / 非新客 / 超领取窗口
- welcome「猜你想问」+ `为您推荐` chips；领券类过滤；RecommendEntry `new_guest_coupon`
- `POST /api/coupons/issue`（`purpose: claim | purchase`）

### 购票闭环

- 多轮对话：问人数 → 问日期 → 可闭环则推荐卡；**不可闭环则兜底 + 跳购票列表**
- **3大1小** 等组合：提示不支持购物车，兜底展示并发放购票优享券（`cp_prod_manual`，与停车券等产品 ID 区分）
- 2大0小 = 成人票×张数；2大1小 = 家庭套票
- 草稿不含游客；`/order/submit` 页选手实名出行人后支付；Mock 支付成功 → **`/orders?tab=1`**（待出行/已完成 Tab）
- ~~VisitorPicker 在聊天内选游客~~（已移至下单页）

### 配置后台

| 页面 | 路径 | 能力 |
|------|------|------|
| 后台配置 | `/config` | 助手 UI + 业务场景（Tab 切换）；右上角可跳转 AI 客服 H5 |
| 助手 UI | `/config/ui` | 名称、配色、欢迎语、头像等 |
| 业务场景 | `/config/business` | Skill 关键词；推荐入口 + 猜你想问（LocalStorage 覆盖） |

### 游后 · 发票 ✅

- **单笔** `/invoice` → `POST /api/invoice/apply` → `/invoice/external` 抬头假页
- **批量** `/invoice/batch` 多选 + `POST /api/invoice/batch`；顶栏/底栏与 H5 内容同宽
- **对话** `invoice_service` → 查可开票订单：有则「您当前有X笔…」+「立即开票」→ `/invoice/batch`；无则「当前没有可申请开票的订单。」
- **快捷推荐** `batch_invoice`（标题「开发票」）→ chat 自动发「开发票」（**不直跳**假页）
- **演示数据** `demo_vip` 含 2 笔 30 天内可开票订单（`ORD20260715*` / `ORD20260710*`）
- **规则字段** `hasInvoiceableOrders`；意图 `shouldRunInvoiceWorkflow` + P0-2 语义路由

### 演出项目推荐 ✅

- **对话** `scenic_recommend` → `runShowScheduleWorkflow`：**单条** `scene_recommend`（文案 + 演出卡）
- **当日** / **明天后天** / **演出推荐（非当日 general）** 文案与推荐场次逻辑区分
- Mock：`activities.json` 灯光秀、花车巡游

### 停车缴费 ✅

- **页面** `/parking` 绑定车牌 / 查询费用 / Mock 支付
- **对话** `parking_pay` Skill → Workflow 查询车牌 + `PageGuideCard` 跳转缴费页
- **演示**：demo_mid（已绑 `粤B·88888`）发「交停车费」；demo_new 发「停车缴费」引导绑定

### 内容数据

- `blocks.json` / `activities.json`（15 项，含分类/排队/热门/虚拟排队）驱动攻略与提醒正文
- **待出行订单**：`upcomingVisitOrder.ts` 按系统当前日期过滤；攻略绑定最近一笔未过期订单
- **demo_mid** 三笔 Mock 订单：2026-06-30 / 2026-07-30 / 2026-08-18；出行日当天欢迎页 **「今日出行」**
- 攻略项目推荐：`in_park` 展示排队，`recommend/full` 前期攻略隐藏排队并提示热门项目
- 详见 [`内容数据配置说明.md`](./内容数据配置说明.md)

## 已知注意点

- Mock 变更（尤其 `mock/_utils.ts`）需 **重启 dev server**；`src/mock/products/*.json` 变更会触发 Mock 重载（见 `vite.config.ts`）
- `demo_new` 注册日 Mock 会在超窗且未领券时自动刷新为「昨天」
- 未配置 `VITE_SILICONFLOW_API_KEY` 时使用离线 Tool fallback
