## v0.2.2（2026-07-21）— 当前 package 版本

**定位**：服务点评「帮我写评价」+ [`场景实现对照表.md`](./场景实现对照表.md)

| 维度 | v0.2.1 | v0.2.2 |

**之后增量（未升 package 号，见项目现状）**：游园日景区点评（去订单、`canScenicReviewToday`、分享后发券、点评管理）、购票资格卡、Mock `@/` 别名修复等。

## v0.2.1（2026-07-21）

**定位**：`scene_recommend`、主动营销推券、演出/发票交互、配置后台规则增强

| 维度 | 增量 |
|------|------|
| 场景卡片 | `scene_recommend` 单条合并（券 + 活动） |
| 主动营销 | 餐饮/零售询问与下单意图 → 推券 + 推荐 |
| 演出 | 单条卡片；当日 / 明日 / 后天 / general |

| 发票 | 「有 X 笔…」+「立即开票」→ 批量页 |
